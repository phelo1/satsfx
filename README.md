# SatsFX - Satoshi Time Machine

What if you bought Bitcoin? A journey through Bitcoin's history and the lost opportunity cost of not being early.

## 🚀 Features

### 1. Timeline of Bitcoin Milestones
Interactive timeline showing key Bitcoin moments from 2009-2024:
- Genesis Block mining
- First Bitcoin transaction (Laszlo's pizza)
- $1 parity
- $1,000 mark
- $20,000 ATH
- $69,000 ATH
- ETF Approval & $120,000 ATH

### 2. "What If" Portfolio Simulator
Enter any past USD investment and see what it would be worth today in Bitcoin. Includes:
- Historical price data from 2009-2024
- Bitcoin amount purchased
- Current value calculation
- Gain multiplier
- Regret meter

### 3. Inflation Time Machine
Slide through time and see what purchases at different moments would be worth today if invested in Bitcoin.

### 4. Vaporization Chart
Visual representation of how USD has lost value against Bitcoin over time, with animated burning effects.

### 5. Child's Bitcoin Birthday Calculator
Enter your child's birthdate (after Bitcoin creation in 2009) and see projected Bitcoin wealth at age 65 based on:
- Pessimistic CAGR (30%)
- Average CAGR (50%)
- Bullish CAGR (75%)

## 💡 The Story

This website demonstrates the power of Bitcoin as a store of value and the opportunity cost of fiat currency holding. Every dollar held since 2009 has lost 99.99%+ of its purchasing power against Bitcoin.
